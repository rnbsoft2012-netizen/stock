# 매일 아침 7시 카톡 브리핑 - 실행 절차

이 문서는 매일 아침 7시(KST)에 깨어나는 Claude Routine이 그대로 따라야 할 절차입니다.
Routine 프롬프트에도 이 내용이 포함되어 있습니다.

## 절차

1. 저장소 루트에서 `python scripts/prices.py` 를 실행해 `portfolio.yaml` 기준
   국내/해외 시세, 등락률, 평가금액, 평가손익을 JSON으로 받는다.
2. 보유 종목마다 PlayMCP 네이버뉴스 검색(`NaverSearch-search_news`)을
   `news_query` 키워드로 호출해 최근 뉴스를 1~2건씩 조회한다.
   국내·해외 모두 네이버뉴스를 쓴다 — 한국어이고 관련도가 Yahoo 검색보다 높다.
   해외 종목은 스크립트가 함께 담아준 Yahoo 헤드라인을 보조로 참고할 수 있다.
3. 종목별 상세 브리핑을 작성한다: 현재가, 등락률, 평가손익, 뉴스 한 줄,
   그리고 그 뉴스와 수치에 근거한 관전 포인트 한 줄.
4. PlayMCP의 카카오톡 나에게 보내기(`KakaotalkChat-MemoChat`)로 전송한다.
   **메시지 1건당 최대 200자**이므로 여러 건으로 나눠 순서대로 보낸다
   (전체 요약 1건 → 종목별 1건씩). 각 메시지 앞에 `[n/N]` 순번을 붙인다.
5. 마지막 메시지 끝에 `* 투자 참고용이며 투자 권유가 아닙니다.` 를 덧붙인다.
6. 전송 실패 시 원인을 파악해 재시도하고, 반복 실패하면 상태를 남긴다.

## 데이터 소스에 대한 메모

- **시세**: 국내·해외 모두 Yahoo Finance chart API를 `requests`로 직접 호출.
  - `yfinance` 라이브러리는 쓰지 않는다. 내부적으로 curl_cffi로 브라우저 TLS
    지문을 위장하는데, 클라우드 세션의 보안 프록시가 그 연결을 리셋한다.
    같은 엔드포인트를 평범한 requests로 부르면 정상 동작한다.
  - `pykrx`도 쓰지 않는다. 최신 pykrx(1.2.8)는 KRX 계정(KRX_ID/KRX_PW) 로그인을
    요구하는데, 클라우드 환경변수에는 안전한 비밀 저장소가 없어 계정 비밀번호를
    두기 적절하지 않다. Yahoo가 국내 종목도 원화로 제공해 한 소스로 통일했다.
    KRX 공식 데이터가 꼭 필요해지면 그때 계정 연동을 다시 검토한다.
- **뉴스**: PlayMCP 네이버뉴스 검색 (국내·해외 공통).

## 전제 조건

- claude.ai 계정에 PlayMCP 커넥터가 연결되어 있고 이 세션에서 사용 가능해야 함
  (카카오톡 나에게 보내기 + 네이버 검색 — 2026-08-06 기준 확인 완료)
- 실행 환경의 네트워크 정책이 `query1.finance.yahoo.com`,
  `query2.finance.yahoo.com` 아웃바운드 접속을 허용해야 함 (확인 완료)
- `portfolio.yaml`에 실제 보유 종목/수량/평단가가 최신 상태로 반영되어 있어야 함
