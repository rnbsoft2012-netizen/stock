# 매일 아침 7시 카톡 브리핑 - 실행 절차

이 문서는 매일 아침 7시(KST)에 깨어나는 Claude Routine이 그대로 따라야 할 절차입니다.
Routine 프롬프트에도 이 내용이 포함되어 있습니다.

## 절차

1. 저장소 루트에서 `python scripts/prices.py` 를 실행해 `portfolio.yaml` 기준
   국내(pykrx)/해외(yfinance) 시세, 등락률, 평가금액, 평가손익, 해외 종목 관련
   yfinance 뉴스 헤드라인을 JSON으로 받는다.
2. `portfolio.yaml`의 국내 종목(domestic) 각각에 대해 PlayMCP 네이버뉴스 검색
   도구로 "{종목명} 주가" 또는 "{종목명}" 키워드로 최근 뉴스를 1~2건씩 조회한다.
3. 아래 형식으로 카카오톡 메시지를 작성한다 (종목별 상세 수준):

   ```
   [내 주식 브리핑] YYYY-MM-DD 아침

   ▍전체 요약
   총 평가금액: N원 (전일대비 ±X%)
   총 평가손익: ±N원 (±X%)

   ▍국내
   - 삼성전자 (005930): 현재가 N원 (±X%) | 평가손익 ±N원(±X%)
     뉴스: <헤드라인 1줄>
     코멘트: <한 줄 투자 아이디어/관전포인트>
   - ... (보유 종목별 반복)

   ▍해외
   - AAPL: $N (±X%) | 평가손익 ±$N(±X%)
     뉴스: <헤드라인 1줄>
     코멘트: <한 줄 투자 아이디어/관전포인트>
   - ... (보유 종목별 반복)

   * 투자 판단의 참고용이며 투자 권유가 아닙니다.
   ```

4. PlayMCP의 카카오톡 "나에게 보내기" 도구로 위 메시지를 전송한다.
5. 전송 실패 시 원인을 파악해 재시도하고, 반복 실패하면 다음 대화에서
   사용자에게 보고할 수 있도록 상태를 남긴다.

## 전제 조건 (사용자가 준비해야 하는 것)

- claude.ai 계정에 PlayMCP 커넥터가 연결되어 있고 이 세션에서 사용 가능해야 함
- 이 실행 환경(environment)의 네트워크 정책이 `data.krx.co.kr` (pykrx) 와
  `query1.finance.yahoo.com` / `query2.finance.yahoo.com` (yfinance) 아웃바운드
  접속을 허용해야 함 — 기본 정책에서는 차단되어 있을 수 있음 (환경 설정에서 조정 필요)
- `portfolio.yaml`에 실제 보유 종목/수량/평단가가 최신 상태로 반영되어 있어야 함
